# Ember-Forge Editor Guide

Ember-Forge is the editor application for building projects, importing assets, arranging scenes,
attaching components, writing Lua gameplay scripts, and launching the standalone runtime.

Use these articles in order if you are new to the editor:

1. [Projects and Scenes](ProjectsAndScenes.md) - create or open a project, understand the project folders, and manage scenes.
2. [Editor Tour](EditorTour.md) - learn the viewport, hierarchy, inspector, asset manager, environment panel, and common shortcuts.
3. [Building a First Scene](BuildingAFirstScene.md) - make a small playable scene with primitives, lights, a camera, and a controller.
4. [Scripting Gameplay](ScriptingGameplay.md) - create Lua scripts, expose properties, and attach behavior to entities.
5. [Building UI](BuildingUI.md) - canvases, buttons and toggles, and wiring them to Lua.
6. [Playtesting and Exporting](PlaytestingAndExporting.md) - run in the editor, launch through Ember-Runtime, and export a project.

For API details while writing scripts, keep the [Scripting API Reference](../ScriptingAPI.md) nearby.
